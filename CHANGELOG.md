# Changelog

Все значимые изменения проекта документируются в этом файле.

---

## [1.0.0] — 2026-08-21

### 🎉 Первый релиз

#### Добавлено
- **Лендинг** — полноценная страница с 8 секциями (герой, о центре, услуги, специалисты, отзывы, галерея, FAQ, контакты)
- **Адаптивный дизайн** — корректное отображение на мобильных (≤480px), планшетах (≤768px), малых десктопах (≤1024px) и больших экранах
- **Мобильное меню** — бургер-кнопка, выдвижная навигация, затемняющий оверлей
- **Анимации при скролле** — плавное появление элементов через IntersectionObserver
- **FAQ-аккордеон** — раскрывающиеся ответы с анимацией
- **Галерея** — слайдер с кнопками навигации
- **Telegram-бот** — отправка заявок с формы в Telegram-группу через Bot API
- **Форматирование телефона** — автоматическое форматирование в формат +7 (___) ___-__-__
- **Валидация формы** — проверка обязательных полей с визуальной обратной связью
- **Безопасность** — секреты Telegram вынесены в `config.js` (не коммитится), шаблон `config.example.js` для разработчиков
- **SEO** — мета-теги title и description, семантическая HTML5-разметка
- **Premium-дизайн** — CSS-переменные, Google Fonts (Inter, Cormorant Garamond, Unbounded), плавные переходы, hover-эффекты

#### Технические детали
- Чистый HTML/CSS/JS без фреймворков и зависимостей
- Mobile-first медиа-запросы с тремя точками разрыва (480px, 768px, 1024px)
- CSS Grid и Flexbox для раскладок
- Sticky-хедер с blur-эффектом при скролле
